# 합격도장

지원하는 회사의 기준으로 서류를 고치고, 그 회사 면접관과 연습하는 AI 취업 준비 서비스예요. 회사 리서치부터 맞춤 서류 작성, 회사 기준 평가, 모의 면접까지 한 사이트에서 하는 AI 취업 준비 서비스예요. 로그인 없이 쓰고, 데이터는 브라우저에 저장돼요.

## 이렇게 써요

1. **내 프로필**: 학력, 경력, 프로젝트, 에피소드를 섹션별로 적어요. 기존 이력서 PDF나 텍스트를 올리면 자동으로 항목을 나눠 채워줘요.
2. **새 지원 회사**: 회사, 직무, 채용공고 링크(또는 본문)와 마감일을 넣어요.
3. **회사 리서치**: 웹 검색과 공고 페이지를 읽고 회사 개요, 인재상, 최근 이슈, 직무 분석, 평가 기준(비중 포함), 면접 포인트를 정리해요. 진행 중에 "무엇을 검색하는 중인지" 보여줘요.
4. **서류 작성**: 자기소개서, 이력서, 경력기술서, 포트폴리오를 지원 건마다 여러 개 만들 수 있어요.
   - 자소서 문항과 글자 수 제한을 넣으면 문항별 글자 수(공백 포함/제외)와 초과·부족을 바로 보여줘요.
   - 프로필에 없는 경험은 지어내지 않고 `[성과 수치 입력]`처럼 빈칸으로 남겨요.
   - "더 간결하게"처럼 원하는 방향으로 고쳐쓰기, 직접 편집, 버전 기록과 되돌리기, 이전 버전과 단어 단위 비교.
   - 본문 전체 복사와 **문항별 복사**(채용 사이트의 문항 칸에 바로 붙이기), .txt/.md 내려받기, 인쇄·PDF 저장.
   - **이전 서류에서 시작하기**: 다른 회사에 쓴 서류를 복사해 와서 고쳐쓰기로 이 회사에 맞게 바꿔요. 예시 지원 건의 서류는 목록에 안 나와요.
5. **회사 기준 평가**: 회사 평가 기준별 점수, 문항별 평가, 원문 → 수정안 형식의 "꼭 고칠 부분", 면접에서 파고들 부분을 줘요. "피드백 반영해 수정본 만들기"로 바로 고치고 다시 평가할 수 있고, 점수 변화가 기록돼요.
6. **면접 연습**
   - 모의 면접: 유형(종합/직무/인성/임원), 질문 수, 난이도(기본/심화/압박), 답변 제한 시간, 음성 모드(질문 읽어주기 + 말로 답하기)를 고를 수 있어요. 면접관이 서류를 근거로 꼬리질문을 하고, 끝나면 역량별 점수와 질문별 "더 나은 답변 예시"를 줘요.
   - 예상 질문: 꼭 나올 질문, 서류 검증 질문, 직무 질문, 압박 질문과 질문 의도, 답변 재료, 답변 구조를 정리해요.
7. **홈 / 개요**: 지원 회사별 진행 상태, 마감 D-day, 단계별 진행도, 서류·면접 점수를 한눈에 봐요.
8. **결과 미리보기**: 랜딩의 "결과 미리보기"나 빈 홈의 "예시로 둘러보기"를 누르면 가상의 회사(한빛페이)로 만든 예시 지원 건이 들어와요. 리서치·서류(초안 → 피드백 반영 두 버전)·채점(72 → 86)·면접 리포트(74)가 모두 채워져 있고, "예시" 표시가 붙어요. API를 부르지 않고 `src/lib/demo.ts`의 고정 데이터를 넣는 거라 비용이 들지 않아요. 개요 탭 아래에서 지울 수 있어요.

## 에이전트

| 에이전트 | 하는 일 | 설정 |
|---|---|---|
| 회사 리서치 | 웹 검색 + 공고 페이지 읽기로 회사 프로필 작성 | web_search, web_fetch, effort medium |
| 서류 작성 | 프로필 × 회사 프로필로 서류 초안 | effort high |
| 첨삭 반영 수정 | 평가 결과나 요청대로 전체 수정본 + 수정 내역 | effort high |
| 회사 기준 평가 | 회사 평가 기준으로 100점 채점, 원문 → 수정안 | effort high |
| 모의 면접관 | 한 질문씩, 꼬리질문, 종료 시 피드백 리포트 | effort low (빠른 응답) |
| 예상 질문 코치 | 예상 질문 20여 개와 답변 전략 | effort medium |
| 이력서 가져오기 | PDF/텍스트 → 프로필 항목 (구조화 출력) | effort low |

모델은 `claude-opus-5-5`이고, 안전 분류기가 요청을 거절하면 다른 모델로 자동 재시도해요(`fallbacks: "default"`). 프롬프트는 `src/lib/agents.ts`에 모여 있어요.

## 실행

```bash
npm install
cp .env.example .env.local   # ANTHROPIC_API_KEY 입력
npm run dev                  # http://localhost:3000
```

- API 키 없이 `npm run dev`로 띄우면 자동으로 **모의 응답 모드**가 돼서 화면을 확인할 수 있어요. 프로덕션에서 모의 응답을 쓰려면 `AGENT_MOCK=1`.

## 배포 (Vercel)

환경 변수:

| 이름 | 필수 | 설명 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 예 | Claude API 키 |
| `APP_ACCESS_CODE` | 권장 | 로그인이 없으니 공개 배포 시 이 코드를 아는 사람만 쓰게 해요. 사용자는 설정 화면에서 입력해요. |
| `RATE_LIMIT_PER_HOUR` | 아니오 | IP당 시간당 요청 수 (기본 60, 0이면 끔). 서버 인스턴스마다 따로 세는 메모리 방식이라 느슨한 장치예요. IP는 Vercel이 넣는 `x-real-ip`를 믿으니, 다른 곳에 올리면 프록시 설정을 확인하세요. |
| `CLAUDE_MODEL` | 아니오 | 모델 변경 (기본 `claude-opus-5-5`) |
| `NEXT_PUBLIC_SITE_URL` | 배포 시 예 | 배포 주소 (예: `https://hapgyeok.example`). sitemap, robots, 공유 미리보기 이미지(OG) 주소에 들어가요. 없으면 `http://localhost:3000`. |

이력서 PDF 가져오기는 Vercel 함수의 요청 크기 한도(4.5MB) 때문에 3MB까지 받아요.

리서치는 1~3분 걸릴 수 있어서 함수 최대 실행 시간을 300초로 잡아 뒀어요. Vercel Hobby 요금제는 최대 60초라 리서치가 끊길 수 있으니 Pro 이상을 권해요.

## 출시 전에 채울 것

- `src/lib/site.ts`: 서비스 이름, 문의 이메일, **사업자 정보**(상호, 대표자, 사업자등록번호, 통신판매업 신고번호, 주소, 전화)와 요금제(`PLANS`). 푸터, 요금, 약관 화면이 모두 여기서 읽어요.
- `src/app/(marketing)/terms`, `privacy`: 이용약관과 개인정보처리방침 **초안**이에요. 화면 위에 초안 안내가 떠 있으니, 전문가 검토 후 안내 문구(`LegalPage`의 `draft`)를 빼 주세요.
- 결제와 로그인은 아직 없어요. 요금 화면의 버튼은 모두 앱(`/app`)으로 연결돼요.
- 보안: 로그인과 결제가 붙기 전에는 **`APP_ACCESS_CODE`를 켜고 초대한 사람에게만 코드를 주세요.** 주소를 아는 누구나 운영자의 API 비용을 쓸 수 있어요. 자세한 점검 결과는 `docs/REVIEW.md` 5차.
- 상표: "합격도장" 이름은 KIPRIS에서 같은 류(9류, 35류, 41류, 42류) 등록 여부를 확인해 주세요.

### 요금 정할 때 참고 (API 원가, 2026-11-08 실측)

실제 Claude API로 작업마다 한 번씩 돌려서 서버 로그의 `[usage]`(토큰, 검색 횟수)로 잰 값이에요. Opus 5.5 정가(입력 $4, 출력 $20, 캐시 쓰기 $5, 캐시 읽기 $0.20 / 100만 토큰, 웹 검색 1,000회당 $10)와 환율 1,400원으로 계산했어요.

- 조건: A4 1장 분량 프로필, 토스 프론트엔드 개발자(공고 URL 없음), 자소서 2문항 × 700자, 면접은 기본 설정(직무 + 인성, 본 질문 7개, 기본 난이도).
- 작업마다 1회만 쟀어요. 문항 수와 글자 수가 늘면 서류 작업 비용도 늘어요. 같은 입력이라도 생각 토큰 양에 따라 ±30% 정도는 흔들릴 수 있어요(추정).

| 작업 | 1회 원가 | 걸린 시간 | 토큰 (입력 / 출력) | 메모 |
|---|---|---|---|---|
| 이력서 가져오기 (텍스트) | 28원 | 8초 | 1.6천 / 0.7천 | |
| 회사 리서치 | 716원 | 1분 44초 | 캐시 쓰기 4만 + 캐시 읽기 16.7만 / 9.8천, 검색 8회 | 작업 환경 제약으로 페이지 읽기(web_fetch) 없이 쟀어요. 배포 환경에서는 공고 페이지를 읽는 만큼 더 들 수 있어요 |
| 서류 작성 | 402원 | 1분 50초 | 8.8천 / 12.2천 | 출력의 약 80%가 생각 토큰 |
| 회사 기준 채점 | 525원 | 2분 21초 | 1.1만 / 1.6만 | 출력의 약 70%가 생각 토큰 |
| 피드백 반영 수정 | 464원 | 1분 43초 | 1.6만 / 1.3만 | |
| 예상 질문 (21개) | 476원 | 2분 17초 | 9.6천 / 1.5만 | |
| 모의 면접 (본 질문 7 + 꼬리질문 8 + 피드백) | 490원 | 질문마다 2~5초, 피드백 58초 | 캐시 읽기 22.8만 / 1.1만 | 18번 호출. 캐시 덕분에 질문 한 번에 12~18원, 피드백 176원 |

생각(thinking)은 Opus 5.5에서 끌 수 없고, 서류 작업 비용의 대부분은 이 생각 토큰을 포함한 출력이에요. 그래서 서류 작업 원가를 낮추는 손잡이는 `src/lib/agents.ts`의 `effort`와 모델이에요. 2026-11-09에 effort와 모델(Opus, Sonnet, Haiku)을 바꿔 가며 원가와 품질을 쟀어요. 이력서 가져오기는 Haiku, 채점·수정·면접은 Sonnet으로 바꾸고 서류 작성은 Opus로 두면 한 바퀴가 약 2,900원으로 줄어요(추정, 지금 프롬프트로 전부 Opus면 약 3,930원). 앱 설정은 아직 바꾸지 않았어요. 자세한 결과는 `docs/REVIEW.md` 10차에 있어요.

**사용 패턴별 원가 (위 실측값으로 계산)**

| 사용 패턴 | 원가 |
|---|---|
| 회사 1곳 한 바퀴: 리서치 → 서류 작성 → 채점 → 수정 → 다시 채점 → 예상 질문 → 면접 2회 | 약 4,100원 |
| 한 달에 회사 5곳 리서치, 서류 작업(작성·수정·채점) 40번, 면접 10번 | 약 2만 7천 원 |

예시 요금 스탠다드 14,900원에서 부가세(10%)와 결제 수수료(약 3%, 추정)를 빼면 남는 돈은 약 1만 3천 원이에요. 회사 1곳 한 바퀴(약 4,100원) 기준으로 한 달 3곳(약 1만 2천 원)까지는 남지만, 위의 "한 달 5곳" 사용자에게는 약 1만 4천 원 적자예요. 출시 전에 아래를 권해요.

- "서류 무제한" 대신 월 횟수 한도(예: 회사 리서치 몇 곳, 서류 작업 몇 번, 면접 몇 번)를 두기
- 출시 후에도 `[usage]` 로그를 모아서 실제 사용자의 원가 분포로 한도와 요금을 다시 맞추기

측정 방법과 품질 검토 결과는 `docs/REVIEW.md` 9차에 있어요.

## 데이터와 개인정보

- 주민등록번호, 외국인등록번호, 운전면허번호, 여권번호, 카드번호는 브라우저에서 보내기 전과 서버에서 한 번 더 가려요 (`src/lib/privacy.ts`). 전화번호와 이메일은 이력서에 필요해서 가리지 않고, 이력서·경력기술서를 쓸 때만 보내요.

- 프로필, 서류, 면접 기록은 이 브라우저(localStorage)에만 저장돼요. 설정에서 JSON 백업을 내려받고 다른 기기에서 불러올 수 있어요.
- 에이전트를 부를 때만 필요한 내용이 서버를 거쳐 Claude API로 전달돼요. 회사 리서치에는 내 프로필을 보내지 않아요.

## 디자인

- 색: 원고지 초록(`brand`, 제목·주요 버튼·선택 상태), 흰 종이(`sheet`), 초록 기가 아주 살짝 도는 바탕(`paper`), 빨간 펜(`pen`)은 채점·첨삭·급한 마감에만, 합격 초록(`pass`)은 80점 이상에만 써요. 회색은 Tailwind 기본 `slate`의 파란 기를 뺀 값으로 덮어써요. 토큰은 `src/app/globals.css`의 `@theme`에 있고, 팔레트를 바꿀 때는 그 파일과 공유 이미지(`src/app/opengraph-image.tsx`), 브라우저 색(`src/app/layout.tsx`의 `themeColor`)만 고치면 돼요.
- 글꼴: 제목과 서류 본문은 함렛(Hahmlet), 화면 글자는 프리텐다드. 둘 다 npm 패키지로 자체 호스팅해요.
- 점수는 둥근 도장(`ScoreStamp`)으로 찍혀요. 80점 이상은 초록 "합격권", 미만은 빨강 "보완 필요".

# 다음에 넣을 만한 기능 (제안)

지침에 따라 아직 만들지 않았어요. 고르시는 것만 만들게요. 순서는 **유료 출시에 필요한 정도**로 매겼어요. 근거가 추정인 곳은 추정이라고 적었어요.

## A. 유료로 받기 전에 꼭 필요한 것

이건 "기능"이라기보다 출시 조건이에요. 지금 상태로는 돈을 받을 수 없어요.

| 순서 | 항목 | 왜 필요한가 | 규모 |
|---|---|---|---|
| A1 | 로그인 (카카오 + 이메일) | 결제한 사람과 안 한 사람을 구분할 방법이 없어요. 로그인 없이 유료는 성립하지 않아요. | 중간 |
| A2 | 서버 저장 (Supabase) | 돈을 낸 사용자의 서류가 브라우저 기록 삭제 한 번에 사라지면 환불·신뢰 문제가 돼요. 휴대폰과 PC를 같이 쓰는 취준생에게 기기 간 동기화도 기본 기대치예요. | 중간~큼 (지금 저장 구조를 옮기는 작업) |
| A3 | 결제 (토스페이먼츠 정기결제) + 요금제별 사용량 한도 | 요금 화면에 적힌 한도를 서버에서 실제로 세야 표시와 동작이 같아져요. | 중간 |
| A4 | 요청별 원가 기록 | 지금 원가는 추정이에요 (README). 실제 토큰·검색 횟수를 남겨야 요금과 한도를 숫자로 정할 수 있어요. 코드 몇 줄이라 A3과 같이 하는 걸 권해요. | 작음 |
| A5 | 실제 API로 품질 점검 | 이 서비스의 핵심 가치(리서치 정확도, 경험 지어내지 않기, 채점 일관성)를 아직 실제 모델로 확인하지 못했어요. 회사 5곳 × 서류 2종 정도로 직접 써 보고 기준을 정하는 걸 권해요. | 작음 (API 키 필요) |

권장 순서: A5 → A1·A2 → A3·A4. A5를 먼저 하는 이유는, 결과물 품질이 기대에 못 미치면 요금 설계와 기능 우선순위가 바뀌기 때문이에요.

## B. 사용자 가치가 큰 기능

| 항목 | 기대 효과 | 비용과 위험 | 의견 |
|---|---|---|---|
| B1 문항별 복사 버튼 | 대부분의 채용 사이트는 문항마다 칸이 따로 있어서, 지금처럼 본문 전체 복사는 다시 잘라 붙여야 해요. | 작음 | **권장.** 작고 매일 쓰는 기능이에요. |
| B2 경험 카드 (STAR 정리) + 회사 간 중복 사용 표시 | 같은 에피소드를 여러 회사, 여러 문항에 돌려 쓰는 게 취준생의 실제 작업 방식이에요. 경험을 카드로 정리해 두면 서류 품질이 일정해지고, 한 회사 안에서 같은 경험을 두 문항에 쓰는 실수를 막아요. | 중간. 프로필 구조가 바뀌어 기존 데이터 이전이 필요해요. | **권장.** 경쟁 서비스와 차별점이 될 수 있어요 (추정, 시장 조사는 안 했어요). |
| B3 이전 지원 서류에서 시작하기 | 비슷한 직무에 낸 서류를 출발점으로 쓰면 시간과 API 비용이 줄어요. | 작음~중간 | 권장. |
| B4 면접 답변 습관 분석 | 답변 시간, 글자 수는 이미 기록해요. 여기에 습관어("음", "그" 반복), 두괄식 여부, 답변 길이 추이를 보여주면 연습 효과가 눈에 보여요. | 작음~중간. 음성 인식 결과는 습관어를 지우는 경우가 있어 정확도가 제한적이에요. | 보통. 글 기반 분석부터 시작하는 걸 권해요. |
| B5 마감 알림 (이메일 또는 카카오 알림톡) | 마감 D-day는 이미 있어요. 알림이 있으면 다시 방문할 이유가 생겨요. | 로그인과 서버가 먼저 필요해요. 알림톡은 발신 프로필 심사가 필요해요. | A1·A2 뒤에. |
| B6 서류 .docx 내보내기 | 포트폴리오·경력기술서는 파일로 내는 경우가 있어요. | 중간 | 수요를 보고 결정. 자소서는 대부분 웹 입력이라 우선순위가 낮아요. |

## C. 지금은 권하지 않는 것

| 항목 | 이유 |
|---|---|
| 영상 면접 녹화·표정·시선 분석 | 얼굴 영상은 민감한 개인정보라 처리방침과 보관 설계가 크게 늘어나고, 표정 분석은 정확도 근거를 대기 어려워요. 비용 대비 효과가 불확실해요. |
| AI 역량검사(게임형) 대비 | 시장은 크지만 지금 제품(서류·면접 코칭)과 다른 제품이에요. 핵심 흐름이 검증된 뒤에 판단하는 게 맞아요. |
| 한글(.hwp) 내보내기 | 형식이 복잡하고 요구하는 기업이 많지 않아요 (추정). |
| 면접관 성격·회사별 페르소나를 더 많이 | 지금도 유형·난이도 설정이 있어요. 선택지를 늘리면 비용과 테스트 범위만 늘고 체감 차이는 작을 가능성이 커요. |
